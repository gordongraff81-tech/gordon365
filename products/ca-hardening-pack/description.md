# Conditional Access Hardening Pack

10 produktionsreife Conditional Access Policies für Microsoft Entra ID
— mit Rollout-Plan, Risikoanalyse und Microsoft365DSC-Export-Bereitschaft.

## Problem

Die meisten Microsoft 365 Tenants laufen bestenfalls mit Microsofts
Security Defaults — einer Einheitslösung, die nicht an das
Risikoprofil einer Organisation angepasst werden kann. Ohne
Conditional Access fehlt der Schutz gegen Legacy-Authentifizierung,
privilegierte Konten haben keine zusätzlichen Auflagen, und es gibt
keine Reaktion auf risikobasierte Anmelde-Signale.

## Was enthalten ist

- 10 Conditional-Access-Policies als maschinenlesbares JSON
  (Microsoft Graph API v1.0 kompatibel)
- Vollständige Implementierungsanleitung (DOCX): zwei Importwege,
  empfohlene Rollout-Reihenfolge, Validierungsschritte
- Risikoanalyse: welches Risiko wird durch welche Policy gemindert
- Business-Impact-Kennzahlen
- Break-Glass-Account-Anleitung
- Microsoft365DSC-Mapping (Phase 2 vorbereitet)

## Für wen

IT-Admins und MSPs, die Tenants über Security Defaults hinaus
absichern wollen — ohne Consulting, mit klarer Schritt-für-Schritt-
Anleitung und Report-Only-Modus als Sicherheitsnetz.

## Voraussetzungen

Microsoft 365 Business Premium, Entra ID P1 (P2 für 2 von 10 Policies).
